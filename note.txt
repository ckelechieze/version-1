1. Initialization: - git init 

2. Staging: 
    (a) git add <filename> (to stage one file)
    (b) git add . (to stage all files)

3. Commit: git commit -m "your commit message here"

4. Push:
    git push -u origin main

5. git branch branch-name - This is used to create a branch
   git checkout branch-name - This is used to navigate into a branch
